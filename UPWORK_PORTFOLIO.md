## Description
A personal backend portfolio project for managing fictional customers and insurance policies with Java, Spring Boot, Maven and H2.

The API provides customer and policy CRUD operations, name search, policy filtering and pagination. It includes input validation, demo business rules, consistent error responses, SQL persistence and unit/integration tests for key success and failure scenarios.

The project includes a clear layered structure, sample data, API examples, a Postman collection and setup instructions. It demonstrates Java backend development, REST API design, database relationships and testing. All data and rules are fictional; this is not a client project.
